# US Honey Production Analysis (1995–2021)

## Project Overview
This project focuses on analyzing honey production in the United States from 1995 to 2021.

The main objective is to understand honey production trends, state-wise production, honey prices, colonies, and yield per colony using Python.

## Dataset Information
- Dataset: US Honey Dataset
- Time Period: 1995–2021
- Number of Records: 1,115
- Number of Original Columns: 9

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Analysis Tasks
1. Data loading and inspection
2. Data cleaning
3. Missing values and duplicate checking
4. State-wise honey production analysis
5. Year-wise production analysis
6. Honey price analysis
7. Colony and yield analysis
8. Outlier detection
9. Correlation analysis

## Visualizations
- Year-wise Honey Production – Line Chart
- Top 10 Honey Producing States – Bar Chart
- Average Honey Price – Line Chart
- Production Distribution – Histogram
- Production Outliers – Box Plot
- Colonies vs Production – Scatter Plot
- Correlation Heatmap

## Key Findings
- The dataset covers 1995 to 2021.
- North Dakota is among the leading honey-producing states.
- US honey production shows a long-term declining trend.
- Honey production, colonies, yield, and prices provide useful insights into the honey industry.

## Conclusion
This project helped me practice data cleaning, exploratory data analysis, data visualization, and extracting meaningful insights using Python.
